# merryxmascc.github.io

Private, password-protected site (Job Hub: job tracker + resume builder).

The published page contains only a login screen and encrypted data (AES-256-GCM, key derived from the password with PBKDF2). Without the password nothing on the site, or in this repo, is readable. Tracker data is synced, encrypted, to the `data` branch.

The previous Christmas-tree site is kept on the [`archive`](https://github.com/merryxmascc/merryxmascc.github.io/tree/archive) branch.
